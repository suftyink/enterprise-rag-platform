# 01: 试点关闭时开放受控知识治理

**What to build:** 让已授权知识管理员在员工试点关闭、readiness 缺失或失败时仍能通过内部 Web 完成文档上传、处理状态查看和知识治理，同时继续阻止员工问答，并保留全部管理员安全控制。

**Blocked by:** None (can start immediately).

**Status:** resolved

- [x] 缺少 `PilotReadiness` 报告时，已授权知识管理员仍可打开治理工作区、查看文档和上传文档。
- [x] 缺少或未通过 readiness 时，员工问答和受保护反馈继续以稳定门禁错误拒绝访问。
- [x] 治理操作继续执行企业身份认证、管理员角色、知识作用域、CSRF、状态机、并发控制和审计检查。
- [x] 普通员工、未认证用户和越权管理员不能因为治理门禁解耦而获得管理能力。
- [x] 页面分别显示“员工试点不可用”和“知识治理可用”，不再用一个全局提示宣称两者同时不可用。
- [x] 同一内部 Web 工作流覆盖管理员可治理、员工仍被门禁阻止以及越权请求被拒绝。

## Answer

治理 Web/API 已改为只依赖企业身份与原有 RBAC、scope、CSRF、状态机和审计控制；员工问答与反馈仍经 `PilotAccessGate` 失败关闭，页面分别表达治理可用和员工试点未开放。
