# 02: 增加分类指标与检索质量门禁

**What to build:** 让评测报告分别展示中文、英文缩写、SKU、数字或表格、模糊问题、无答案及租户隔离案例，并根据试点阈值给出机器可判定的通过或失败结果。

**Blocked by:** 01 / 运行版本化检索评测.

**Status:** ready-for-agent

- [ ] 报告同时包含总体指标和各必需分类指标。
- [ ] 无答案案例计算拒答准确率。
- [ ] 跨租户返回任一未授权结果时泄漏计数增加且整体失败。
- [ ] Recall@5 低于 90%、MRR@5 低于 0.80 或拒答准确率低于 90% 时失败。
- [ ] 分类为空、标签不完整或样本不足时报告明确为不可判定而非通过。
- [ ] 生产基线要求至少 100 条经人工复核的真实业务案例。
