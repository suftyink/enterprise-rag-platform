# 03: 恢复部分索引并统一重建路径

**What to build:** 让索引在数据库、对象存储或向量写入中途失败后可安全重试和补偿，新版本失败时保留旧可用版本，并让活动索引重建复用相同的 Indexer 规则。

**Blocked by:** 02 / 处理索引幂等与分类失败.

**Status:** ready-for-agent

- [ ] 向量写入后数据库失败或数据库写入后向量失败均可被检测和恢复。
- [ ] 补偿或重试不会删除当前仍可用的旧版本。
- [ ] 新版本失败不改变旧版本的检索资格。
- [ ] 无法立即清理的产物产生可重试清理记录。
- [ ] 重建活动索引使用相同解析、Embedding 和版本约束。
- [ ] 重复重建保持幂等并报告真实结果。
