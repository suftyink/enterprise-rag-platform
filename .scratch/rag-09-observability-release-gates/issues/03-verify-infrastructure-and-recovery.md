# 03: 纳入真实基础设施、容量与恢复证据

**What to build:** 让试点就绪报告纳入真实 PostgreSQL、Redis、MinIO、Milvus、Celery 和模型组合验证，以及有界负载、备份恢复、索引重建、Profile 回滚和孤儿清理演练结果。

**Blocked by:** 02 / 汇总生产试点就绪门禁.

**Status:** ready-for-agent

- [ ] 生产类环境完成真实基础设施的上传、索引、检索和回答验证。
- [ ] Celery 重试、Worker 中断和积压场景产生正确结果与告警。
- [ ] 预期试点负载下记录吞吐、P50、P95、错误率和资源水位。
- [ ] 数据库备份恢复后知识状态和审计保持一致。
- [ ] Milvus 索引可从已发布数据库及对象产物重建。
- [ ] 模型或索引 Profile 可回滚到上一合格版本。
- [ ] 孤儿向量和对象清理失败可检测、重试和核销。
- [ ] 未通过的基础设施或恢复证据使 readiness 报告失败或不可判定。
