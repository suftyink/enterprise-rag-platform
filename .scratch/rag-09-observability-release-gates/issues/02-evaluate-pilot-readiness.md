# 02: 汇总生产试点就绪门禁

**What to build:** 让 `PilotReadiness.evaluate()`汇总生产配置、依赖健康、检索和回答评测、安全审计及关键运行信号，输出逐项通过、失败或不可判定的机器可读报告。

**Blocked by:** 01 / 贯通安全 Trace 与关键运行信号.

**Status:** ready-for-agent

- [ ] 配置检查验证 OIDC、模型路由、索引维度、数据库迁移、存储和 Worker 一致性。
- [ ] 门禁只接受与当前数据集、索引、模型和配置匹配的新鲜评测报告。
- [ ] Recall@5、MRR@5、拒答、引用支持率和租户泄漏使用既定阈值判定。
- [ ] 任一租户泄漏、无效引用或缺少关键审计事件直接阻止发布。
- [ ] 缺失证据显示为 indeterminate，不被默认为通过。
- [ ] 报告包含版本、时间、证据引用和安全摘要，不包含敏感正文。
- [ ] 失败门禁提供可操作原因且不自动执行生产发布。
