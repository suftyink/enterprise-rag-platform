# 03: 支持回滚、清理补偿与并发审计

**What to build:** 让审核者可把文档回滚到此前有效版本，运营人员可追踪和重试跨存储清理，并通过修订号防止并发覆盖，使完整生命周期保持可恢复和可审计。

**Blocked by:** 02 / 审核发布与撤回知识版本.

**Status:** ready-for-agent

- [ ] 可选择一个仍有完整索引产物的历史版本执行回滚。
- [ ] 回滚原子切换检索资格，失败时保留原发布版本。
- [ ] 删除或撤回产生幂等的对象与向量清理任务。
- [ ] 清理失败可见、可重试且不会恢复文档的检索资格。
- [ ] transition 接受 expected revision，并拒绝过期的并发操作。
- [ ] 生命周期审计事件不可变并包含动作、主体、原因、版本和结果。
- [ ] 同内容但不同文档身份的去重行为符合明确版本策略。
