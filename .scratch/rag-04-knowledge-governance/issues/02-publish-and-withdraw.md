# 02: 审核发布与撤回知识版本

**What to build:** 让授权审核者检查处理结果后发布一个版本，并能立即撤回已发布版本；发布切换保持一个明确的当前版本，撤回后即使向量仍存在也不可检索。

**Blocked by:** 01 / 分离文档处理状态与发布状态.

**Status:** ready-for-agent

- [ ] 审核者可查看版本、处理警告、来源和 Chunk 摘要后决定发布。
- [ ] 只有处理成功且待审核的版本可以发布。
- [ ] 发布新版本后 Retriever 只返回新的当前发布版本。
- [ ] 发布失败时原发布版本继续可用。
- [ ] 撤回后 PostgreSQL 资格检查立即阻止该版本进入检索。
- [ ] 非法状态转换返回明确错误且不改变现有状态。
- [ ] 每次发布或撤回记录操作者、原因、时间和修订号。
