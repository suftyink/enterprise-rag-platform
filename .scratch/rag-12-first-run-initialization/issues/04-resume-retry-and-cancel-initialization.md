# 04: 支持初始化恢复、重试和取消

**What to build:** 让初始化作为持久化后台工作跨浏览器会话可靠推进；管理员能够观察进度、从可重试故障恢复或安全取消，并确保并发启动、Worker 中断和配置变化不会生成重复资源或把半成品投入服务。

**Blocked by:** 03 / 安全 Provision 并核验 Milvus 物理索引.

**Status:** resolved

- [x] 每个数据分类最多存在一个非终态初始化运行；竞争幂等键得到包含可恢复运行身份的稳定冲突。
- [x] 长时间操作由 Worker 执行并持久化阶段、进度、lease/heartbeat、Attempt、稳定失败码和可重试性，浏览器请求不持有长事务。
- [x] 关闭浏览器、应用重启或重新登录后，管理员可以继续观察并操作同一初始化运行。
- [x] Worker 心跳丢失或 lease 过期会收敛为可观察的失败状态，不会永久停留在“处理中”。
- [x] 输入指纹未变化时，重试从最早失效阶段继续并安全复用已完成产物；配置或语料变化时创建新的 Attempt 或候选身份。
- [x] 取消阻止后续阶段启动、产生审计记录，并保证未完成 Profile、索引或 Release 永远不具备员工检索资格。
- [x] 页面准确显示阶段、Attempt、进度、安全错误、可重试性及下一动作，并使用 revision 防止陈旧操作覆盖新状态。
- [x] 内部 Web 测试覆盖重复点击、竞争启动、故障注入、跨会话恢复、Worker 失联、重试和取消后的服务隔离。

## Answer

初始化运行已持久化 revision、Attempt、阶段、进度、lease、错误码和审计；数据库部分唯一索引阻止同分类并发所有者。重试复用 Profile/索引，陈旧 revision 被拒绝，过期 Worker lease 转为可重试失败，取消后不会进入活动发布链。
