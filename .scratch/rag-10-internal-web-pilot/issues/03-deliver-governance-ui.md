# 03: 交付知识管理员治理工作流

**What to build:** 让授权知识管理员在浏览器中上传四种支持格式、查看处理结果和警告、审核发布，并能撤回或回滚版本；所有操作由服务端权限和状态机保护。

**Blocked by:** 01 / 交付员工登录、提问、答案与引用主路径.

**Status:** ready-for-agent

- [ ] 管理员可选择 PDF、DOCX、Markdown 或 HTML 并在上传前看到限制。
- [ ] 上传后可查看处理阶段、结果、警告、版本和解析信息。
- [ ] 待审核内容不会在员工问答中出现。
- [ ] 授权管理员可发布、撤回和回滚其管理范围内的版本。
- [ ] 广范围或破坏性动作显示文档、版本、作用域并要求明确确认。
- [ ] 越权操作即使构造浏览器请求也被服务端拒绝。
- [ ] 每个治理动作与审计记录及 trace 关联。
- [ ] 与员工问答界面共享一致的错误和状态语言。
