# 03: 交付知识管理员治理工作流

**What to build:** 让授权知识管理员在浏览器中上传四种支持格式、查看处理结果和警告、审核发布，并能撤回或回滚版本；所有操作由服务端权限和状态机保护。

**Blocked by:** 01 / 交付员工登录、提问、答案与引用主路径.

**Status:** resolved

- [x] 管理员可选择 PDF、DOCX、Markdown 或 HTML 并在上传前看到限制。
- [x] 上传后可查看处理阶段、结果、警告、版本和解析信息。
- [x] 待审核内容不会在员工问答中出现。
- [x] 授权管理员可发布、撤回和回滚其管理范围内的版本。
- [x] 广范围或破坏性动作显示文档、版本、作用域并要求明确确认。
- [x] 越权操作即使构造浏览器请求也被服务端拒绝。
- [x] 每个治理动作与审计记录及 trace 关联。
- [x] 与员工问答界面共享一致的错误和状态语言。

## Answer

已交付四格式上传、授权范围内的文档清单、处理/发布状态、解析警告与版本信息，以及带文档、版本、范围和原因确认的发布、撤回与回滚。服务端复用既有身份授权和 `KnowledgeCorpus` 状态机，浏览器隐藏控件不替代权限校验。
