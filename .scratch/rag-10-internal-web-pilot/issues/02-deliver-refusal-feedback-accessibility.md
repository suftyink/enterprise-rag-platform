# 02: 交付拒答、错误、反馈与无障碍体验

**What to build:** 让员工能区分证据不足、输入问题、无权限和临时系统故障，对一次答案提交反馈，并通过键盘、焦点和语义状态完成主要问答流程。

**Blocked by:** 01 / 交付员工登录、提问、答案与引用主路径.

**Status:** ready-for-agent

- [ ] `INSUFFICIENT_KNOWLEDGE` 显示为正常拒答而非系统错误。
- [ ] 校验错误、授权拒绝和临时故障具有不同且可操作的提示。
- [ ] 可重试故障允许安全重试且不会重复反馈或请求副作用。
- [ ] 员工可提交评分和简短原因，反馈关联当前 answer trace。
- [ ] 模型或文档内容按不可信输入安全渲染。
- [ ] 问答、引用和反馈流程可完全使用键盘操作。
- [ ] 控件具有语义标签、可见焦点、可读对比和状态播报。
