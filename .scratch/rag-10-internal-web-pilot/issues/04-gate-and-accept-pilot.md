# 04: 通过浏览器验收并受控开放生产试点

**What to build:** 让代表性员工和知识管理员在生产类环境完成约定浏览器工作流，并仅在当前 `PilotReadiness` 报告通过、负责人和回滚方案明确时开放内部试点功能。

**Blocked by:** 02 / 交付拒答、错误、反馈与无障碍体验; 03 / 交付知识管理员治理工作流.

**Status:** ready-for-agent

- [ ] 浏览器验收覆盖登录、提问、引用、拒答、错误和反馈。
- [ ] 浏览器验收覆盖上传、处理、审核、发布、撤回和回滚。
- [ ] 验收使用真实身份、真实知识、真实模型和生产类基础设施。
- [ ] 关键无障碍和内容注入场景通过同一浏览器工作流验证。
- [ ] 只有当前、完整且通过的 PilotReadiness 报告允许开启试点开关。
- [ ] 开放记录包含批准人、范围、容量、监控和回滚责任人。
- [ ] 门禁失效或出现安全事件时可关闭试点而不删除知识数据。
- [ ] Function、GraphRAG、Agent、IM 和写操作不进入本次验收。
