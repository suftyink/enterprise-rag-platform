# 02: 对无支持或无效回答失败关闭

**What to build:** 让回答模块识别未知引用、缺少证据的事实、格式无效、证据冲突、发布状态变化和模型故障，任何无法验证的结果都不作为事实答案返回。

**Blocked by:** 01 / 生成带代码绑定引用的回答.

**Status:** ready-for-agent

- [ ] 模型引用未知 evidence ID 时结果被拒绝。
- [ ] 非拒答事实单元缺少有效引用时结果被拒绝。
- [ ] 无效结构化输出不会退化为未经校验的纯文本答案。
- [ ] 冲突证据按契约显示限定条件或返回明确拒答。
- [ ] 返回前发现证据已撤回或失去权限时不暴露该答案。
- [ ] 模型超时、限流和不可用与正常证据不足具有不同结果。
- [ ] 所有失败结果保留安全 trace ID 且不记录提示词或正文。
