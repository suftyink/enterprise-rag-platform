# 03: 建立回答反馈与质量门禁

**What to build:** 让员工能针对一次回答提交评分和原因，并让版本化评测计算引用支持率与回答拒答准确率，使无效案例可进入复核队列且不自动污染知识库。

**Blocked by:** 02 / 对无支持或无效回答失败关闭.

**Status:** ready-for-agent

- [ ] 反馈关联 answer trace、决定、评分、原因和可信主体。
- [ ] 重复提交具有明确幂等或修订行为。
- [ ] 自由文本反馈不会自动成为索引或发布知识。
- [ ] 低评分和引用问题可导出为人工复核候选。
- [ ] 评测报告计算代码绑定引用的支持率。
- [ ] 引用支持率低于 95% 或回答拒答准确率低于 90% 时门禁失败。
- [ ] 反馈和评测记录不复制不必要的敏感正文。
